# AI Powered Language Translator

This practice Coursera project involves a voice translation assistant which can convert spoken words to text, translate the text to another language using a LLM and then play the translated speech.

We utilise Watsonx's mistralai/mistral-large LLM model for translation.

The Flask framework is used to for the web app and server side processing of the chatbot. It also handles the management of all HTTP requests and responses.

IBM Watson Speech Libraries for Embed are used for STT and TTS.

HTML, CSS and JavaScript files were already provided for the layout, structure and interactivity of the web page / web interface.
